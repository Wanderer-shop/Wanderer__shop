จะแสดงคำแนะนำเรื่อง MAIL/PASS, GitHub-Gmail, ช่องทางติดต่อ และระยะเวลารอ 1–3 วันบนหน้าร้าน

เชื่อมต่อ Cloudflare Worker และ Google Sheets

แจ้งเตือนจะส่งจากหน้าเว็บไป Cloudflare Worker โดยตรง ไม่เรียก Google Apps Script ในเส้นทางแจ้งเตือน ส่วน Google Sheets ใช้เป็นแหล่งข้อมูลสำรอง/นำเข้าสินค้าได้

วาง URL /exec ที่เผยแพร่ให้เข้าถึงได้ แล้วระบบจะลองอ่าน JSON หรือ CSV จาก URL นี้ก่อน หากไม่กำหนดจะใช้ URL CSV แยกด้านล่าง

ระบบจะรวมข้อมูลลงในแท็บจัดการหมวดหมู่/แอป/แพ็กเกจเดิม โดยจัดหมวดตามชื่อชีต เช่น แอพพรีเมี่ยม, เติมเหรียญนิยาย, เติมเกม และสติ๊กเกอร์ไลน์; หาก URL ว่างหรือดึงข้อมูลไม่สำเร็จจะคงข้อมูลเดิมไว้

แนะนำใช้ Google Apps Script Web App URL /exec ซึ่งรองรับ JSON หรือ CSV ได้ใน URL เดียว; หากไม่ใช้ ให้ใส่ CSV แบบฟิลด์ระบบ (id, name, categoryId, appId, price ฯลฯ) หรือ CSV ตารางภาษาไทย: หมวดหลัก (ชื่อแอป), รายละเอียดแอป, หมวดหมู่แพ็กเกจ/กลุ่มตัวเลือกแพ็กเกจ/ตัวเลือกแพ็กเกจ (หมวดหมู่ย่อย), ชื่อแพ็กเกจย่อย, ราคา, ลิงก์รูป, รายละเอียดแพ็กเกจ, สถานะ, ID; หาก Apps Script ส่งหลายชีตควรแนบชื่อชีตในฟิลด์ sheetName หรือ categoryName หากใช้ /pubhtml ระบบจะลองแปลงเป็น URL CSV ให้อัตโนมัติ ทั้งนี้เบราว์เซอร์/Google อาจปฏิเสธการอ่านข้ามโดเมนได้
